# Каталог наследия народов Кузбасса

Сайт каталога нематериального этнокультурного наследия шорцев и телеутов: главная страница и самостоятельная страница поиска и паспортов объектов.

## Запуск

Требуется Node.js 20.19+ или 22.12+ (включая актуальные версии 24+).

```powershell
npm install
npm run dev
```

Локальный адрес Vite будет указан в терминале. Производственная сборка и тесты:

```powershell
npm run build
npm test
```

## Каталог

Отдельный вход: `/Reestr3/catalog/`. Паспорта открываются по постоянному параметру `record`, фильтры сохраняются в URL. Работают поиск, совместимые фильтры, сортировка, список/карточки, пагинация, связи с предметами, фотогалерея и CSV.

Наполнение и структура данных описаны в [CATALOG-CONTENT.md](CATALOG-CONTENT.md). Проверка данных: `npm run catalog:validate`, автоматически выполняется перед сборкой. Публичная часть статическая; серверная админка и общая база данных пока не вводились.

## Содержание

Тексты новых карточек временные, подготовлены по разрешению владельца и отмечены как ожидающие научной редакции. В предметных карточках используются обработанные фотографии двух бубнов из съёмки проекта. Неизвестные шифры, датировки и сохранность не выдумываются. Границы ареалов и режим использования медиаматериалов требуют согласования.

Источники и происхождение материалов перечислены в [public/SOURCES.md](public/SOURCES.md).

## GitHub Pages

Публикация выполняется автоматически из ветки `main` через GitHub Actions. Vite собирает сайт с базовым путем `/Reestr3/`, после чего workflow публикует папку `dist`.

Адрес проекта после успешного workflow: `https://harajuku7.github.io/Reestr3/`.
