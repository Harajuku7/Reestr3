# Каталог наследия народов Кузбасса

Сайт каталога нематериального этнокультурного наследия шорцев и телеутов: главная страница и самостоятельная страница поиска и паспортов объектов.

## Запуск

Требуется Node.js 20.19+ или 22.12+ (включая актуальные версии 24+).

```powershell
npm install
npm run dev
```

Локальный адрес Vite будет указан в терминале. Производственная сборка и тесты:

```powershell
npm run build
npm test
```

## Каталог

Отдельный вход: `/Reestr3/catalog/`. Паспорта открываются по постоянному параметру `record`, фильтры сохраняются в URL. Работают поиск, совместимые фильтры, сортировка, список/карточки, пагинация, связи с предметами, фотогалерея и CSV.

Наполнение и структура данных описаны в [CATALOG-CONTENT.md](CATALOG-CONTENT.md). Проверка данных: `npm run catalog:validate`, автоматически выполняется перед сборкой. Публичная часть статическая; серверная админка и общая база данных пока не вводились.

## Содержание

Тексты новых карточек временные, подготовлены по разрешению владельца и отмечены как ожидающие научной редакции. В предметных карточках используются обработанные фотографии двух бубнов из съёмки проекта. Неизвестные шифры, датировки и сохранность не выдумываются. Режим использования медиаматериалов требует согласования.

Источники и происхождение материалов перечислены в [public/SOURCES.md](public/SOURCES.md).

## Карта на главной

Карта использует локальный `src/kuzbass-map-data.geo.json`: обзорный контур области из geoBoundaries, координаты населённых пунктов и реки из OpenStreetMap. Научные справки подтверждают выбранные места проживания шорцев и телеутов. Точки не изображают этнические границы и не заменяют полный список поселений.

`src/SettlementMap.jsx` отвечает за Leaflet-интерфейс, `src/settlement-map.css` - за оформление, `src/map-interaction.mjs` - за настройки взаимодействия и фильтрацию. Есть плавный масштаб +/-, колесо / pinch, перемещение, сброс к области и полноэкранный режим. Внешняя подложка OSM показывает дороги, населённые пункты и улицы при увеличении. `src/kuzbass-districts.geo.json` содержит отдельный слой 13 южных городских и муниципальных округов, не всех муниципалитетов области. Геолокация и сетевой геокодер при просмотре не используются; сетевые запросы подложки описаны в `public/PRIVACY.md`. Научные сведения и скачивание двух GeoJSON перенесены в кнопку информации. Постоянной текстовой панели под картой больше нет.

Первая локальная приёмка: `../research/kuzbass-registry/2026-10-22-verified-map/README.md`. Актуальная интерактивная итерация: `../research/kuzbass-registry/2026-10-22-map-explorer/README.md` в рабочей папке LABA AI. Статус публикации подтверждается завершённым workflow GitHub Pages и проверкой публичного сайта. Геоконтроль исходного набора сохранён в `src/map-geometry.test.mjs`; новое взаимодействие и муниципальная принадлежность проверяются в `src/map-interaction.test.mjs`.

## GitHub Pages

Публикация выполняется автоматически из ветки `main` через GitHub Actions. Vite собирает сайт с базовым путем `/Reestr3/`, после чего workflow публикует папку `dist`.

Адрес проекта после успешного workflow: `https://harajuku7.github.io/Reestr3/`.
